# RO 口袋戰記寵物圖鑑

《RO仙境傳說：口袋戰記》寵物圖鑑，提供寵物資料查詢、羈絆篩選與排序。這是靜態網頁，不需要後端服務或安裝相依套件。


## 功能

- 依寵物名稱搜尋，或依分類篩選。
- 勾選羈絆並設定最低符合數，查看符合的寵物與羈絆星數。
- 依星數、寵物名、分類、屬性、體型、戰鬥定位、技能及符合的羈絆排序，支援升冪／降冪。
- 桌面版可點選表格欄名排序；手機版以資訊卡呈現，並提供排序選單。

## 本機使用

直接以瀏覽器開啟專案中的 `index.html` 即可使用。

## 發布到 GitHub Pages

將 `index.html` 與 `README.md` 放在 GitHub 儲存庫根目錄，推送變更後，確認儲存庫的 **Settings → Pages** 已設定發布來源，即可透過 Pages 網址瀏覽。
